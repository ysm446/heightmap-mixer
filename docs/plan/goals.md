# goals — プロジェクトの目的と完成形

作成日時: 2026-08-31 05:46
更新日時: 2026-08-31 12:09

## 目的

Quixel Mixer に相当する、ハイトマップと PBR テクスチャをレイヤー合成してマテリアルを
オーサリングし、それを地形に適用できるデスクトップアプリケーションを自作する。

## 完成形

1. レイヤースタック方式のマテリアル合成
   - 各レイヤーが PBR チャンネルセット（BaseColor / Normal / Roughness / Metalness / Height / AO）を持つ。
   - レイヤーはマスクとブレンドモードで積み重ねる。
   - 単純なアルファ合成ではなく、**ハイトベースブレンド**を中核に据える
     （岩の隙間に砂が溜まるような、高さ関係に基づく自然な境界）。
   - マスクはプロシージャル生成（ノイズ / 傾斜 / 高度 / 曲率 / AO）とペイントの両方に対応する。

2. リアルタイム PBR プレビュー
   - Cook-Torrance GGX + IBL（irradiance + prefiltered specular + BRDF LUT）。
   - 物理カメラベースの露出（EV100）に対応し、マニュアルと自動露出を切り替えられる。
   - トーンマップを通した、他 DCC / ゲームエンジンと比較可能な見た目。

3. 地形オーサリング
   - ハイトマップのインポートと LOD 付き地形描画。
   - 作成したマテリアルを地形にスプラット適用する。
   - 地形の高度 / 傾斜 / 曲率を、そのまま合成側のマスク入力として使えるようにする。

4. 実用的な出力
   - フル解像度でのテクスチャセット書き出し（チャンネルパッキング設定を含む）。
   - 他のエンジンに持ち込んで同じ見た目が再現できること。

## 重視する価値

- **リアルタイム性**: 合成は GPU compute で評価し、編集操作に対して即座にプレビューが更新される。
- **物理的な正しさ**: 露出と IBL を物理量ベースで扱い、見た目の基準をぶれさせない。
- **非破壊編集**: レイヤーとパラメータは常に編集可能で、評価は毎回そこから再生成される。
- **段階的に動くもの**: 各マイルストーンの終わりに必ず起動して触れる状態を保つ。

## 現在の到達点

M3 まで完了。レイヤー合成とハイトベースブレンド、PBR プレビュー（直接光 + IBL）、
物理カメラの露出までが動いている。詳細は [progress.md](progress.md) を参照。

## 当面の非目標

以下は最初から作らない。必要になった時点で改めて検討する。

- メッシュのスカルプト、UV 展開、リトポロジー。
- 高精度なメッシュベイク（ハイポリからのノーマル / AO ベイク）。
- Windows / DirectX 12 以外のプラットフォームおよび API への対応。
- アセットライブラリのオンライン連携、共同編集、クラウド機能。
- ノードグラフ方式の汎用テクスチャ生成（レイヤー内部のマスク生成の拡張として将来検討）。
