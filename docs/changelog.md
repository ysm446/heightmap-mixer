### 2026-08-31 15:49 — ステータスバー、ファイルのドロップ、EXR 表示の修正

- **画面下端にステータスバーを追加した。**
  左に直近の通知（保存した、読み込めなかった、など）と、いまのモード。
  右にプロジェクト名・レイヤー / マテリアル / テクスチャの数・合成解像度・FPS。
  **これまで警告やエラーはデバッグ出力にしか出ておらず、
  読み込みが成功したのかどうか画面からは分からなかった。**
- **エクスプローラからファイルをドロップできるようにした。**
  拡張子で行き先が決まる（画像 → テクスチャ / `.mmproj` → プロジェクト /
  `.mmmat` → マテリアル / `.hdr` → 環境）。扱えない形式は理由を出す。
- **EXR のサムネイルが真っ暗に近かったのを直した。**
  EXR の中身はリニアで、ImGui はその値をそのまま描くため極端に暗くなっていた。
  読み込み時に sRGB へ焼いた表示用テクスチャを作るようにした。
- 読み込んだテクスチャを選択して一覧に見せるようにした
  （一覧はスクロールするので、末尾に足すだけでは気づけなかった）。

### 2026-08-31 15:12 — M5b: テクスチャ一覧と、プロジェクト / マテリアルの保存

- **テクスチャパネル**を追加した（レイヤー・マテリアルと同じ枠の 3 つめのタブ）。
  読み込んだ画像をサムネイルで一覧でき、解像度・ミップ数・形式・参照数・置き場所を確認できる。
  名前を付け替えられ、使わなくなった画像は削除できる。
  **サムネイルをマテリアルのマップ欄へドラッグすると割り当たる。**
  画像の読み込み口はマテリアルパネルからこちらへ移した。
- **プロジェクトの保存と読み込み**（`.mmproj`）。
  レイヤー / マテリアル / テクスチャの参照 / ペイントマスク / プレビュー設定を保存する。
  ファイルメニューに 新規 / 開く / 保存 / 名前を付けて保存 / 終了 を追加。
  タイトルバーに開いているプロジェクト名が出る。
  - **マテリアルの構造はプロジェクトへ丸ごと埋め込む。** 開くのに別ファイルは要らない。
  - 画像は参照だけを持ち、パスはプロジェクトからの相対で記録する。
    プロジェクトごと移動しても壊れない。
  - ペイントマスクは手続きで再現できないので、`<名前>.assets/` へ PNG で書き出す。
- **マテリアル単体の書き出しと読み込み**（`.mmmat`）。
  マテリアルパネルの「書き出し…」「読み込み…」から、プロジェクト間で持ち回れる。
  読み込むと参照している画像も自動で読み込まれ、既に持っている画像は読み直さない。
- 形式は JSON で、値は名前で書いてある（[docs/reference/file-format.md](reference/file-format.md)）。
  手で開いて読める。壊れたファイルは断り、画像が見つからないときは
  その割り当てだけ「なし」にして残りを読む。
- 起動オプション `--project <path>` を追加（起動時にプロジェクトを開く）。

### 2026-08-31 18:52 — プロジェクト名を material-mixer に変更

- 名前を `heightmap-mixer` から **`material-mixer`** に変えた。
  扱っているのは BaseColor / Normal / Surface / Height の 4 チャンネルを持つマテリアルで、
  ハイトマップはその 1 チャンネルとハイトブレンドの駆動値にすぎない。
  実行ファイルは `material_mixer.exe`、ウィンドウのタイトルは `Material Mixer`。
- 内部の識別子もそろえた。`namespace hm` → `namespace mm`、`HM_*` → `MM_*`
  （C++ のマクロ、HLSL の定数、インクルードガード）。
- レイアウトの保存先が `material_mixer_imgui.ini` に変わるため、
  パネル配置は一度既定に戻る。

### 2026-08-31 18:04 — チャンネルパックされたテクスチャと EXR に対応

- **Megascans の `_ORD` のように、1 枚に複数のマップを詰めたテクスチャを使えるようにした。**
  ラフネス / メタルネス / AO / ハイトは「テクスチャ + どのチャンネルを読むか」で指定する。
  マスク用テクスチャも同じ。
- マテリアルパネルに `ORD` 行を追加。1 枚を選んで「割り当て」を押すと、
  AO=R / ラフネス=G / ハイト=B にまとめて割り当てる（Megascans の並び）。
  個別に選び直せるので、並びが違う素材（UE の ORM など）にも対応できる。
- **EXR (.exr) の読み込みに対応した。** 16bit float のまま持つので、
  ハイトに 8bit の階段が出ない。Megascans のテクスチャをそのまま使える。

### 2026-08-31 17:12 — M5a: マテリアルライブラリ（サムネイル付き）

- **マテリアル**を追加した。PBR のマップ一式（ベースカラー / 法線 / ラフネス /
  メタルネス / AO / ハイト）に名前を付けたもので、**レイヤーはこれを 1 つ参照する**。
  マップを 1 枚ずつ差し替えるのではなく、マテリアルを差し替えて見た目を変える。
- **マテリアルパネル**を追加（レイヤーのとなりのタブ）。
  サムネイルの一覧から選び、マップとパラメータを編集できる。
- サムネイルは球にマテリアルを当てて描く。一覧で見比べられる。
- **テクスチャの読み込みがファイル選択ダイアログになった。** 複数まとめて選べる。
  HDRI も同じくダイアログから開く。パスの手入力欄は廃止。
- マテリアルを割り当てたレイヤーでは、色とサーフェスの値はマテリアル側で決まる。
  レイヤー側の同じ項目は隠れる（同じ意味の値が 2 か所にあると分からなくなるため）。
- マスク用のテクスチャはレイヤー側に残した。マスクは「どこに出すか」を決めるもので、
  マテリアルの「何を出すか」とは役割が違う。

### 2026-08-31 16:02 — パネルをドックに収め、レイアウトのリセットを追加

- **右のパネルが画面外へはみ出して見切れる問題を修正した。**
  パネルを絶対座標で置いていたため、ウィンドウの大きさが変わったときや、
  別の大きさで保存されたレイアウト(ini)を読んだときに収まらなくなっていた。
  すべてのパネルをドックへ収める形に変え、ウィンドウの大きさに必ず追従するようにした。
- `表示 > レイアウトをリセット` を追加。パネルの配置を既定へ戻す。

### 2026-08-31 15:24 — 座標系を右手系に統一し、座標軸ギズモを追加

- ビューポートの座標系を**右手系 Y-up** に統一した。X が右、Y が上、Z が手前。
  これまでは左手系の行列を使っていたため画面が左右反転しており、
  ワールドの +X が画面左に出ていた。対称なプリミティブでは気づきにくい状態だった。
- あわせて**ビューポートのドラッグの向きが直った**。
  左ドラッグでもパンでも、ドラッグした向きに内容が付いてくる。
- ビューポートの左下に**座標軸ギズモ**を追加。X = 赤 / Y = 緑 / Z = 青で、
  奥を向いている軸は暗く表示する。

### 2026-08-31 14:36 — UI をグレー基調に整理

- 配色をグレー基調に作り直した。彩度をほぼ持たせず、明度だけで面の階層を作る。
  アクセントは 1 色だけで、チェックや「既定値から変えた印」にしか使わない。
- **すべての設定値を「パラメータ名：値」の 2 列に揃えた。** 見出し・幅・ツールチップも統一。
- 各行の右端に**既定値マーカー**を追加。既定値から変えてある項目が一目で分かり、
  押すと既定値へ戻る。
- スライダーは Ctrl + クリックで数値を直接入力できる（入力欄は別に置かない）。
- **レイヤーの並べ替えをドラッグ＆ドロップにした。**「上へ」「下へ」ボタンは廃止。
- ウィンドウのクライアント領域を 1920x1080 に固定した。
  UI もその面へ 1:1 で載せるので、モニタの表示スケールで作業面積が変わらない。
- 開発用オプション `--screenshot-ui <path>` を追加。
  UI 込みのウィンドウ全体を PNG に書き出す。画面キャプチャに頼らずに見た目を確認できる。
- UI のルールを [docs/design/design-guide.md](design/design-guide.md) にまとめた。

### 2026-08-31 13:32 — M4b: ペイントマスク（ブラシ）

- マスクの出どころに「ペイント」を追加。ビューポート上でブラシを引いて、
  レイヤーのマスクを直接描けるようになった。
  プロシージャルでは狙えない場所（ここだけ苔、この一筆だけ砂）を指定できる。
- ペイントモード中は左ドラッグで塗り、右ドラッグで消す。
  視点を回すときは Alt + 左ドラッグ。中ボタンのパンとホイールのズームはそのまま。
- **ブラシの半径は画面上の見た目で決まる。** 視点を近づけても遠ざけても、
  UV スケールを変えても、カーソルの円の大きさどおりに塗れる。
- ブラシの強さ・減衰、消しゴム、全消去、全塗り。
- アンドゥ / リドゥ（24 段）。単位は 1 ストローク。
- ペイント解像度を 512 / 1024 / 2048 から選べる。
  変更しても描いた内容は拡大縮小して引き継ぐ（履歴は破棄される）。
- レイヤーを複製するとペイントマスクも中身ごと複製する。
  レイヤーを削除するとペイントマスクも破棄する。

### 2026-08-31 11:13 — M2b: IBL（環境光）

- 環境マップによるライティング（IBL）に対応。
  拡散は irradiance キューブ、鏡面はラフネス別にプリフィルタしたキューブと
  環境 BRDF の LUT を使う分割和近似。
- Radiance HDR (.hdr) の読み込みに対応。UI からパスを指定して読み込める。
- HDRI を読み込んでいないときは手続き的な空を使う。
  天頂色・地平色・地面色・輝度を UI から調整でき、即座に環境が作り直される。
- 背景（スカイボックス）の表示に対応。
- 環境光の強さを UI から調整できるようにした。
- 開発用のコマンドラインオプションを追加。
  `--hdri <path>` で起動時に HDRI を読み込み、
  `--screenshot <path>` でビューポートを PNG に書き出して終了する。
