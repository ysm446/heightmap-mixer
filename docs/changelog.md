# Changelog

## 未リリース

### 2026-08-31 12:02 — M3b: テクスチャレイヤー

- レイヤーのチャンネルに画像を割り当てられるようにした。
  ベースカラー / 法線 / ラフネス / メタルネス / AO / ハイト / マスクの 7 スロット。
- PNG / TGA / JPG の読み込みに対応。レイヤーパネルからパスを指定して読み込める。
- 読み込んだ画像はミップを自動生成するため、縮小して使ってもざらつかない。
- ベースカラーは sRGB、それ以外はリニアとして正しく読む。
  同じ画像をどちらの用途にも使える。
- ハイトとマスクの出どころに「テクスチャ」を追加。
  ハイトテクスチャを使った合成ができるようになった。
- 起動オプション `--texture <path>` を追加（繰り返し指定可）。

### 2026-08-31 11:52 — ビューポート操作の修正

- ビューポートをドラッグするとカメラと同時にパネルまで動いてしまう問題を修正。
- ウィンドウの移動をタイトルバーからだけに限定した。
- ビューポート上のホイールがウィンドウのスクロールに取られないようにした。
- 右ドラッグでも平行移動できるようにした。

### 2026-08-31 11:37 — M3a: レイヤー合成エンジン

- レイヤースタックによるマテリアル合成に対応。
  レイヤーごとにベースカラー・ラフネス・メタルネス・AO・ハイト・マスクを設定でき、
  ハイトベースブレンドで積み重ねられる。
- ハイトとマスクの出どころとしてフラクタルノイズを用意。
  法線はハイトの勾配から自動的に作られる。
- マスクのレベル調整と反転に対応。
- レイヤーが書き込むチャンネル（BaseColor / Normal / Surface / Height）を個別に切り替えられる。
- 合成結果をプレビューのメッシュに貼れるようにした。合成解像度は 512 / 1024 / 2048 から選べる。
- レイヤーパネルを追加（追加 / 複製 / 削除 / 並べ替え / 有効切り替え）。
- 既定のレイヤー構成を「岩の隙間に砂が溜まる」2 レイヤーにした。

### 2026-08-31 11:13 — M2b: IBL（環境光）

- 環境マップによるライティング（IBL）に対応。
  拡散は irradiance キューブ、鏡面はラフネス別にプリフィルタしたキューブと
  環境 BRDF の LUT を使う分割和近似。
- Radiance HDR (.hdr) の読み込みに対応。UI からパスを指定して読み込める。
- HDRI を読み込んでいないときは手続き的な空を使う。
  天頂色・地平色・地面色・輝度を UI から調整でき、即座に環境が作り直される。
- 背景（スカイボックス）の表示に対応。
- 環境光の強さを UI から調整できるようにした。
- 開発用のコマンドラインオプションを追加。
  `--hdri <path>` で起動時に HDRI を読み込み、
  `--screenshot <path>` でビューポートを PNG に書き出して終了する。

### 2026-08-31 10:46 — M2a: PBR プレビューレンダラ（直接光まで）

- 球 / 平面 / キューブを GGX 直接光で描画するプレビューを追加。
  ベースカラー、ラフネス、メタルネスを UI から調整できる。
- 物理カメラベースの露出に対応。絞り / シャッター / ISO から EV100 を求める方式と、
  EV を直接指定する方式を切り替えられる。
- トーンマップを追加（なし / Reinhard / ACES）。
- ディレクショナルライトの方位角・仰角・照度（lux）・色を調整できるようにした。
- 軌道カメラを追加。ビューポート上で左ドラッグ回転、中ドラッグ平行移動、ホイールでズーム。
- 高 DPI ディスプレイに対応。UI が拡大されず、描画も等倍解像度で行われるようになった。
- ウィンドウが画面からはみ出さないよう、起動時にモニタの作業領域へ収めるようにした。

### 2026-08-31 10:12 — M1: RHI の整備

- D3D12MemoryAllocator を導入し、テクスチャ / バッファの生成とディスクリプタ確保を集約。
- フレームごとに巻き戻るアップロードリングバッファを追加（既定 16 MB/フレーム）。
- GPU 参照中のリソースをフレーム同期後に解放する遅延破棄キューを追加。
- DXC によるシェーダのランタイムコンパイルと、`shaders/` の更新検出によるホットリロードを追加。
- 全パス共通のグローバルルートシグネチャと、コンピュート PSO のキャッシュを追加。
- bindless（SM 6.6 `ResourceDescriptorHeap`）を全面採用。
  起動時に Resource Binding Tier 3 を要求する。
- 疎通確認用のコンピュートシェーダ（fBm + 傾斜マスク）と、その結果を映すプレビューウィンドウを追加。
- `USE_PIX` を常時定義し、Release でも PIX マーカーが有効になるようにした。

### 2026-08-31 06:18 — M0: 基盤の立ち上げ

- CMake + vcpkg（manifest モード）によるプロジェクト構成を追加。
  構成プリセット `x64`、ビルドプリセット `x64-debug` / `x64-release`。
- Win32 ウィンドウと DirectX 12 のデバイス、コマンドキュー、スワップチェーン、
  フレーム同期を実装。
- RTV / SRV 用のディスクリプタアロケータを追加。
- Dear ImGui（docking ブランチ）を統合。日本語フォントの読み込みに対応。
- Debug ビルドでデバッグレイヤーと GPU ベースバリデーションを有効化。
  フレームに PIX マーカーを追加。
- DirectX 12 Agility SDK の DLL をポストビルドで `D3D12/` へ配置。
